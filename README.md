\# LinkedIn Job Parser



Застосунок на Python і Django для збору, збереження та експорту даних про вакансії. Проєкт використовує PostgreSQL для зберігання інформації та підтримує експорт даних у CSV.



\## Можливості



\- Збір даних про вакансії за допомогою парсера.

\- Збереження та керування даними через Django ORM.

\- Використання PostgreSQL як основної бази даних.

\- Експорт вакансій у формат CSV.

\- Налаштування підключення до бази даних через змінні середовища.



\## Технології



\- \*\*Python\*\* — основна мова програмування.

\- \*\*Django\*\* — вебфреймворк.

\- \*\*PostgreSQL\*\* — база даних.

\- \*\*SQLite\*\* — підтримка локальної або попередньої бази даних, якщо використовується в проєкті.

\- \*\*CSV\*\* — формат експорту даних.



\## Вимоги



\- Python 3.13 або сумісна версія.

\- PostgreSQL.

\- Git.



\## Встановлення та запуск



\### 1. Клонування репозиторію



```bash

git clone https://github.com/YOUR\_USERNAME/linkedin-job-parser.git

cd linkedin-job-parser

```



Заміни `YOUR\_USERNAME` на свій логін GitHub.



\### 2. Створення віртуального середовища



Для Windows CMD:



```cmd

python -m venv venv

venv\\Scripts\\activate

```



\### 3. Встановлення залежностей



```cmd

pip install -r requirements.txt

```



\### 4. Налаштування змінних середовища



Створи файл `.env` у кореневій папці проєкту, використовуючи `.env.example` як шаблон.



Заповни змінні відповідно до свого середовища:



\- `DJANGO\_SECRET\_KEY` — секретний ключ Django.

\- `DJANGO\_DEBUG` — режим налагодження.

\- `DJANGO\_ALLOWED\_HOSTS` — дозволені хости.

\- `DB\_NAME` — назва бази даних.

\- `DB\_USER` — користувач PostgreSQL.

\- `DB\_PASSWORD` — пароль PostgreSQL.

\- `DB\_HOST` — адреса сервера бази даних.

\- `DB\_PORT` — порт PostgreSQL.



Не публікуй файл `.env`, паролі або секретні ключі.



\### 5. Застосування міграцій



Переконайся, що PostgreSQL запущений, а база даних створена. Потім виконай:



```cmd

python manage.py migrate

```



\### 6. Запуск Django



```cmd

python manage.py runserver

```



Після запуску відкрий у браузері:



http://127.0.0.1:8000/



\## Структура проєкту



```text

├── config/             # Налаштування Django

├── jobs/               # Логіка роботи з вакансіями

├── manage.py           # Керування Django-проєктом

├── migrate\_data.py     # Міграція даних, якщо потрібна

├── requirements.txt    # Залежності Python

├── .env.example        # Приклад змінних середовища

├── .gitignore          # Файли, виключені з Git

└── README.md           # Документація проєкту

```



\## Безпека



\- Секретні ключі та паролі зберігаються у змінних середовища.

\- Локальна база даних і резервні копії не додаються до репозиторію.

\- Перед використанням парсера необхідно враховувати правила доступу та умови використання відповідного вебсайту.
